# Code availability

This repository provides available custom scripts, parameterized helpers, checksum manifests, and a repository integrity verification script supporting the manuscript's reproducibility materials.

Run the repository integrity check with:

```bash
bash checks/verify_repository_integrity.sh
```

Full re-execution of analyses from source data requires obtaining third-party source datasets from their original public releases and configuring local file paths as described in `analysis/README_analysis.md` and `analysis/scripts/README_scripts.md`. The repository does not redistribute third-party source data.
