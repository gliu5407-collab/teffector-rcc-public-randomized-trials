# Data availability

This study used publicly available or published de-identified datasets. Source trial datasets should be obtained from the original public releases and published supplementary materials cited in the manuscript.

- IMmotion150 source data were obtained from the public cBioPortal/iAtlas/DataHub study files.
- JAVELIN Renal 101 source data were obtained from the published supplementary materials of the JAVELIN Renal 101 biomarker analysis.
- CheckMate/Braun source data were obtained from the published supplementary materials of the CheckMate renal-cell carcinoma analysis.

This repository provides derived non-identifying analysis outputs, manuscript-ready Supplementary Tables S1-S18, audit reports, checksums, and source-data notes. It does not redistribute source patient-level clinical tables, raw expression matrices, raw supplementary workbooks, controlled-access data, or identifiable information. Users should consult `data_source_notes/THIRD_PARTY_DATA_REDISTRIBUTION_POLICY.md` before adding any source data to a local copy.
