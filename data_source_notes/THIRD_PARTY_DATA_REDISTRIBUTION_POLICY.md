# Third-party data redistribution policy

This repository is intended to provide manuscript-ready derived results, supplementary tables, audit reports, and code/documentation for the public cross-trial reanalysis.

It does **not** re-distribute third-party source clinical-trial datasets, raw RNA-seq matrices, cBioPortal study files, raw supplementary workbooks, or any controlled-access data. Users should obtain source data from the original public releases, cBioPortal/iAtlas, or the published supplementary materials cited in the manuscript.

The repository may include derived aggregate results, audit manifests, and supplementary tables generated for the manuscript. Any patient-level source tables that are subject to third-party redistribution restrictions should not be uploaded here.
